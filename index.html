Mesh-compressor github

Языковая модель (9-gram) обучена на 452K реальных и синтетических mesh-сообщений. Она предсказывает следующий символ по контексту из 9 предыдущих. Чем точнее предсказание — тем меньше бит нужно.

Арифметическое кодирование кодирует весь текст как одно дробное число, используя вероятности из модели. Это даёт сжатие близкое к теоретическому пределу — энтропии текста.

LZW-сжатие lzwCompress.js github

Сжатие и декомпрессия LZW без потерь, реализованная на JavaScript для строк.
